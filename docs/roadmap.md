# نقشهٔ راه: از صفر تا `mem` قابل استفاده

> سه فاز، نه بیشتر. هر فاز مستقلاً قابل استفاده است: اگر پروژه در P0 متوقف شود، هنوز یک سیستم حافظهٔ کارکن داری.
>
> **وضعیت:** P0، P1 و P2 پیاده شده‌اند. این سند معیارهای پذیرش هر فاز و «تعریف v1 تمام شد» را نگه می‌دارد؛ کارهای باقیمانده در `HANDOFF.md` (بخش «Still to do») پیگیری می‌شوند.

---

## P0 — انبار + CLI + خواندن در Claude Code (نیم روز)

**می‌سازیم**

- ساختار پوشه در `~/.agents/memory/`، `git init`.
- `mem` (Python، فقط کتابخانهٔ استاندارد): `index`، `recall`، `read`، `write`.
- `PROTOCOL.md` + یک خط ارجاع در `~/.agents/AGENTS.md`.
- دو هوک Claude Code: `SessionStart` (ایندکس) و `UserPromptSubmit` (انتخاب).

**معیار پذیرش**

- یک حافظه نوشته می‌شود، در `MEMORY.md` ظاهر می‌شود، و در پرسش مرتبط تزریق می‌شود.
- `SessionStart` با ۳۰۰ حافظه، زیر ۱۵۰ms.
- اگر خط ایندکس دستی خراب شود، `mem index` درستش می‌کند.

**چرا اول:** بیشترین ارزش با کمترین کد؛ از روز اول حافظه بین ایجنت‌ها مشترک می‌شود.

## P1 — MCP + opencode + DSH + اتصال Claude Code (یک روز)

**می‌سازیم**

- `mem mcp` (stdio): `memory_read`، `memory_write`، `memory_search`.
- اتصال Claude Code: `autoMemoryEnabled: false` در `~/.claude/settings.json`، ثبت MCP، و چند خط جهت‌دهی در `~/.agents/AGENTS.md`.
- opencode: `instructions[]` + MCP.
- پلاگین DSH: `systemPrompt.section()` + `agent/pre-step`.

**معیار پذیرش**

- در Claude Code، حافظهٔ بومی خاموش است (نه در `/memory` نوشته می‌شود، نه `autoDream` اجرا می‌شود) و ابزارهای `mem` در دسترس‌اند.
- opencode با فراخوانی ابزار حافظه را پیدا می‌کند.
- DSH ایندکس را در system prompt می‌بیند.
- یک حافظه که با DSH نوشته شد، در سشن بعدی Claude Code خوانده می‌شود.

## P2 — استخراج + dream (یک روز)

**می‌سازیم**

- `mem extract`: یک فراخوانی کوچک، معیارهای ذخیره/عدم‌ذخیره، اسکن راز، `memory_write`.
- هوک `Stop` (Claude Code/Qoder) و `agent/turn-stopping` (DSH) → اجرای detached با تایم‌اوت ۲۰s.
- `mem dream`: شمارش سشن در `.state/state.json`، قفل pid، ادغام تکرار، جایگزینی متناقض، پاک‌کردن خط مرده، `dream.log`، کامیت git.

**معیار پذیرش**

- در یک سشن واقعی حداکثر چند حافظهٔ معقول نوشته می‌شود؛ خروجی خالی هم رایج است.
- پایان سشن بیش از ۲۰۰ms بلاک نمی‌شود.
- `mem dream` دو بار پشت‌سرهم = بار دوم هیچ diff (idempotent).
- نوشتن کلید API رد می‌شود.

**هشدار:** اگر استخراج نویز داد، خاموشش کن. سیستم بدون استخراج هم کامل کار می‌کند.
